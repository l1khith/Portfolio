AutoFlow: A Secure Automation Framework for Android

Authors: Yamini G, Likhith, Bharat Bhushan, Chiranjeevi M.G., Dhanush Kharvi

Presents AutoFlow, an Android smartphone automation system featuring a Unified Multi-Trigger Architecture (Geofencing, Timing, Wi-Fi, Bluetooth) and a 7-Layer Permission-Based JavaScript Sandbox. Eliminates continuous GPS battery drains while executing user scripts under strict runtime sandboxing.
